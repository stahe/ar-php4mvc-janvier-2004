# نهج تطوير MVC للويب/PHP4

➡️ دورة ذات صلة: **[منهجية تطوير MVC لتطبيق ويب بلغة PHP4](https://stahe.github.io/ar-php4mvc-janvier-2004/)**

يقدم هذا المستند **نهجًا لتطوير تطبيقات الويب باستخدام PHP استنادًا إلى بنية MVC (Model–View–Controller)**.

لا يهدف هذا المستند إلى تقديم طريقة جامدة، بل **تقديم أفكار وإطار عمل** لتصميم تطبيقات الويب المنظمة وفقًا لنموذج MVC. وبالتالي، سيتمكن كل مطور من تكييف هذا النهج **مع احتياجاته وأدواته وتفضيلاته في التطوير**.

## الغرض من هذا المستند

- اقتراح **منهجية تطوير** لتطبيقات الويب بلغة PHP
- هيكلة تطبيق وفقًا **لنموذج MVC المعماري**
- توضيح الفصل بين المسؤوليات بين:
  - **النموذج**: إدارة البيانات ومنطق الأعمال؛
  - **الواجهة**: العرض وواجهة المستخدم؛
  - **وحدة التحكم**: تنسيق التفاعلات بين النموذج والواجهة;

يهدف هذا النهج إلى تحسين:;

- **قابلية صيانة الكود**؛
- **قابلية قراءة البنية**؛
- **قابلية إعادة استخدام المكونات**؛
- **الفصل الواضح للمسؤوليات**؛

## فلسفة النهج

المنهجية المقترحة **مفتوحة وقابلة للتكيف** عن قصد.
وهي بمثابة **دليل هيكلي** أكثر من كونها إطار عمل صارم.

سيكون كل فريق أو مطور قادرًا على:

- تكييف القواعد المتفق عليها;
- تعديل تنظيم المكونات;
- دمج أطر عمل أو مكتبات إضافية;
